# درخواست داده برای پایلوت اعتبارسنجی (TRL 5)

**هدف:** اعتبارسنجی مدل‌های سامانه روی داده واقعی یک واحد صنعتی. داده‌ها می‌توانند **ناشناس‌شده** باشند (تگ‌ها با کد جایگزین شوند)؛ هیچ داده شخصی لازم نیست.

## حداقل داده مورد نیاز
| داده | حداقل | بهتر |
|---|---|---|
| تجهیزات (مشخصات، ضخامت اسمی و حداقل مجاز) | ۵۰ | ۲۰۰+ |
| ضخامت‌سنجی (UT/CML) در چند دوره بازرسی | ۳۰ تجهیز با ≥ ۴ دوره | ۱۰۰ تجهیز با ≥ ۶ دوره |
| سوابق NDT با نتیجه و نوع عیب | ۲۰۰ رکورد | ۱٬۰۰۰+ |
| سیگنال خام PAUT/ToFD/A-scan با **برچسب کارشناس** | ۲۰۰ (≥ ۲۰ از هر نوع عیب) | ۱٬۰۰۰+ |
| سوابق تعمیر/تعویض (برای حذف افزایش‌های غیرفیزیکی) | — | ✔ |
| ارزیابی RBI قبلی (در صورت وجود) | — | برای مقایسه رتبه ریسک |

## منبع‌های رایج
CMMS/SAP PM، نرم‌افزار IDMS/RBI موجود (مثل Meridium/Credo)، فایل‌های Excel بازرسی، خروجی دستگاه UT/PAUT.

## نحوه تحویل
CSV/Excel/JSON یا کوئری SQL فقط‌خواندنی؛ تبدیل ستون‌ها و واحدها با `python -m app.normalize` (راهنما: `docs/PILOT/02-data-contract.md`).
سپس: `python -m app.validate --equipment e.csv --thickness t.csv --ndt n.csv --signals DIR` گزارش دقت را می‌سازد.

## محرمانگی
داده فقط روی سرور پایلوت (On-Premise یا ابر اختصاصی) پردازش می‌شود؛ هیچ داده‌ای به سرویس خارجی ارسال نمی‌شود (سامانه آفلاین کار می‌کند).
